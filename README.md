# reinforcement_practice

Gymnasium - https://gymnasium.farama.org/index.html - To Create Environment

Stable-Baselines3 - https://stable-baselines3.readthedocs.io/en/master/ - is a set of reliable implementations of reinforcement learning algorithms in PyTorch

We can also write reinforcement learning algorithms on our own like I wrote actor-critic, DDPG, DQN

The agents created using reinforcement learning algorithms play in the environments created using Gymnasium and learn to survive in the environments
